# FRG-Door-Pop-Script
the Door Pop Script is a standalone FiveM roleplay script made to improve realism for law enforcement, This script allows players to pop/open specific vehicle doors using individual keybinds. 

## FRG Mods - Door Pop Script

Standalone FiveM resource.

* Default Keybinds:
* NUMPAD 4 = Left Front Door
* NUMPAD 6 = Right Front Door
* NUMPAD 7 = Left Rear Door
* NUMPAD 9 = Right Rear Door
* NUMPAD 8 = Hood
* NUMPAD 5 = Trunk

Install:
1. Drag the doorpop folder into your resources folder.
2. Add this to server.cfg:
   ensure doorpop
3. Restart your server.

Players can change keybinds in:
Settings > Key Bindings > FiveM
